About Me

I'm a Control and Automation Engineer pursuing my M.Sc. at Yıldız Technical University. My core interest is the sim-to-real pipeline — the engineering discipline of ensuring that a system modeled mathematically actually behaves correctly when running on physical silicon under real-world conditions.

My approach follows the V-model rigorously: I design and tune complex control logic in MATLAB/Simulink, validate through MIL and SIL testing, then implement the verified algorithms as production-grade bare-metal C on STM32 platforms with a strict layered architecture (BSP → Middleware → Application). I enforce MISRA-C standards and use logic analyzers for hardware-level debugging.

I interned at Baykar Technologies (maker of the Bayraktar TB2 drone) in the Control, Guidance & Navigation team, working on EKF-based battery state estimation and observer-based fault detection for UAV systems. I also developed transmission ECU control algorithms — gear shift logic and unit tests — on a defense platform under NDA.

Outside of formal work, I co-founded RoboHexa, an independent project to rebuild the hexapod firmware from scratch as a professional-grade, MISRA-compliant codebase — transforming university prototyping code into something deployable.

"My goal is to design systems where mathematical modeling and solid software engineering come together. A beautiful controller that can't run on hardware is just theory. Firmware without a proper model is just guessing."

01 / 04
Hexapod Robot
Kinematics · Sim2Real · SIL Testing · Real-Time Control
Graduation Project
Overview & Contributions

Six-legged walking robot built from model to metal. The IK solver and gait algorithm were developed entirely in Simscape Multibody before a single line of firmware was flashed — SIL testing via Simulink C Caller blocks caught stability bugs that would have been extremely hard to debug on hardware.

  • Rigid-body physics model in Simscape Multibody including MPU6050 IMU
  • Custom Inverse Kinematics derived and validated in simulation before hardware
  • SIL pipeline: C code validated in Simulink, then deployed to STM32
  • Real-time roll/pitch estimation via accel+gyro fusion → PID balance loop
  • Microswitch tactile feedback — state machine adapts gait to terrain contact
  • RF remote controller for manual override
Technical Highlights & Outcome
  • Sim2Real pipeline: bugs caught in simulation = zero hardware surprises
  • SIL testing eliminated math edge cases in IK and gait stability in software
  • Sensor fusion corrects gyro drift via accelerometer — no magnetometer needed
  • Tactile foot sensing creates environmental model without range sensors
  • Stable locomotion on flat and uneven surfaces verified
  • Full sim-to-real transfer successfully completed

02 / 04
Quadcopter Flight Controller
STM32F4 · ESEKF · Quaternion AHRS · Cascade PID
Active Development
Overview & Contributions

Complete flight controller written from scratch in C — no off-the-shelf stacks. Every layer from SPI driver to Kalman filter to control loop was designed manually. Core: a 6-State Error-State EKF (ESEKF) fusing gyro, accelerometer, and magnetometer into a quaternion-based attitude estimate with online gyro bias correction.

  • Full flight controller in C on STM32F4 — no RTOS, no library stacks
  • Low-level SPI driver for ICM20948 9-axis IMU built from register level
  • 6-State ESEKF for AHRS — quaternion attitude + online gyro bias estimation
  • Cascaded control: inner angular-rate loop + outer attitude angle loop
Technical Highlights & Outcome
  • ESEKF in error-state space avoids quaternion normalization issues and reduces linearization error vs. standard EKF
  • Online gyro bias estimation: filter stays accurate as sensor warms during flight
  • Cascade architecture separates rate/angle dynamics — each loop independently tunable
  • Full bare-metal: tight control over timing and interrupt priorities
  • Stable quaternion attitude estimation verified across all axes
  • Responsive attitude tracking with cascaded control confirmed

03 / 04
Quadcopter Modeling, Control & Fault Detection
6-DOF Simulation · Cascade Control · Observer-Based FDD
Baykar Technologies
Overview & Contributions

High-fidelity 6-DoF quadcopter simulation with a fault-tolerant control focus. Motor failures detected and classified using only model-based residuals. Developed within Baykar's CNS team.

  • Full 6-DOF model: cascade control from position setpoint to individual motor commands
  • Observer-based FDD via residual generation between model prediction and actual output
  • Residual projection + isolation logic: identifies exactly which motor is faulty
  • Fault classification: stuck motor vs. partial thrust loss, under vs. over-thrust
  • Validated under realistic disturbance and fault injection scenarios
Technical Highlights & Outcome
  • Model-based FDD: faults appear as statistical residuals — zero extra hardware needed
  • Fault isolation logic reduces false positives — correctly attributes failures to individual rotors
  • Reliable fault detection under realistic noise conditions verified
  • Correct classification across multiple failure mode scenarios

04 / 04
Battery Modeling & SoC/SoH Estimation
LiPo Cell Model · EKF · BMS Fault Detection
Baykar Technologies
Overview & Contributions

Detailed electrochemical LiPo battery model with real-time SoC and SoH estimation via Extended Kalman Filter. Goes beyond a basic equivalent circuit — per-cell tracking, hysteresis OCV, temperature-dependent dynamics, and BMS fault detection.

  • Cell-level model: hysteresis OCV, temp-dependent resistance, thermal coupling, capacity degradation
  • EKF for real-time SoC/SoH with 2D lookup tables for temperature/SoC dependencies
  • Detection algorithms for cell imbalance, voltage sensor drift, and other BMS faults
  • Validated under varying load profiles, temperatures, and degradation scenarios
Technical Highlights & Outcome
  • Hysteresis-aware OCV improves estimation at mid-SoC where standard curves are flat
  • EKF handles temperature and SoC dependencies simultaneously — critical for aerospace BMS
  • Cell-level tracking detects individual cell degradation, not just pack voltage drop
  • Accurate SoC estimation under dynamic load conditions verified
  • Early detection of cell imbalance and sensor drift faults demonstrated
